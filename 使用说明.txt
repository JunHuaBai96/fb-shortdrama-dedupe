【它是干什么的】

对已经剪好的短剧素材做"特征层去重"，让同一个母版裂变出多条
底层特征完全不同、但画面内容正常的素材，对应 Meta 判重的四层：

  1. 画面层  —— 放大 + 非对称随机裁切 + 回填原尺寸、微旋转、
                亮度/对比度/饱和度/色相随机、轻噪点、锐化
                （镜像默认关闭，原片有字幕时不会把字幕翻反）
  2. 音频层  —— 音高微变(±1.2%内) + 速度补偿 + 音量微调 + 可选叠加BGM
  3. 结构层  —— 起点微偏移(改变时长与首帧) + 随机变速(±2.2%内)
  4. 文件层  —— 元数据全清(拍摄设备/GPS/时间) + 去版本指纹 +
                随机 CRF/GOP/音频码率 + 全新编码输出(全新MD5)

每个版本的每一项参数都随机生成、互不相同，并全部写入
"_去重记录_日期.csv"，方便追溯哪个账号用了哪条参数。

输出保持 1080x1920 (9:16)、画面无黑边无畸变、时长基本不变。

───────────────────────────────────────────────────────────────
【快速上手：双击"一键去重.bat"】

1. 双击「一键去重.bat」
2. 把视频文件(或整个文件夹)拖进黑窗口，回车
3. 每个视频生成几个版本？  直接回车 = 5
4. 选强度：  1=轻度  2=标准(推荐)  3=强力
5. 原片有硬字幕？  1=有（镜像关，保护字幕） 2=无（可开镜像）
6. 字幕处理？  1=保留  2=模糊盖住底部字幕带（之后自己重新加字幕）
7. 输出目录  直接回车 = 工具目录下的 output\
8. 要叠 BGM 就把 bgm 文件夹拖进去，不要就回车
9. 有账号列表 txt 就拖进去（自动生成分配表），没有就回车
10. GPU 加速  直接回车=自动检测   2=只用 CPU
11. 并发数  直接回车=自动（GPU 4 路 / CPU 2 路）
12. 按 y 开始，跑完去 output\ 目录拿文件

也可以直接把 1 个视频或整个文件夹拖到「一键去重.bat」图标上。

───────────────────────────────────────────────────────────────
【命令行方式（批量矩阵用）】

  # 自动检测 GPU，有字幕时默认关镜像
  dedupe.py -i input/ -n 5

  # 强制用 NVENC，手动开镜像（无字幕素材）
  dedupe.py -i input/ -n 8 --gpu nvenc --mirror on

  # 有字幕：关镜像 + 模糊盖住底部字幕，之后自己重新加字幕
  dedupe.py -i input/ -n 8 --mirror off --subs cover --subs-area 0.12

  # 强制 CPU、并发 4、叠 BGM
  dedupe.py -i input/ -n 10 --gpu cpu --jobs 4 --bgm bgm/

参数说明：
  -i    视频文件或文件夹（会递归扫描所有子文件夹）
  -o    输出目录（默认 output\）
  -n    每个视频生成几个版本（默认 5，上限 50）
  --mode  light / standard / strong（默认 standard）
  --gpu   auto / nvenc / qsv / amf / cpu（默认 auto）
          auto 会自动探测 N卡/Intel核显/AMD 显卡
  --jobs  并发任务数（默认：GPU 4 / CPU 2）
  --mirror on / off（默认 off，原片有字幕时千万别开）
  --subs  keep / cover（默认 keep；cover 用模糊条遮住底部字幕带）
  --subs-area  字幕带高度占比（cover 模式用，默认 0.12 = 12%）
  --bgm       BGM 文件夹，多条 BGM 会轮流叠加到各版本
  --accounts  账号列表 txt（一行一个账号名），生成"账号-素材"分配表
  --tag       输出文件名前缀，比如剧名
  --seed      随机种子，同一种子结果可复现

───────────────────────────────────────────────────────────────
【三个强度怎么选】

  light    只改画面裁切+调色+编码，画质损失最小。
           适合：本来就要人工精修的高价值素材、二压前最后一步。
  standard 推荐。画面+音频+结构全改，人眼几乎无感，
           过审稳定性好。日常量产用这个。
  strong   幅度更大（裁切 6-8%、变速±2.2%、噪点更明显）。
           适合：被平台标记过的素材、同剧已发过多条要拉开差异。

  强度越高画面越"松"，别无脑全用 strong。

───────────────────────────────────────────────────────────────
【GPU 加速】

自动检测支持的硬件编码器：NVIDIA NVENC / Intel QSV / AMD AMF。
实测（1080x1920 / 15秒素材 / 4路并发 / RTX 5060 Ti）：

  CPU libx264：  约 6.0 秒/条
  GPU NVENC：    约 2.4 秒/条

  提升约 2.5 倍。

如果 GPU 编码失败（显存不足/驱动问题），工具会自动回退到 CPU 编码，
不会中断任务。

───────────────────────────────────────────────────────────────
【原片字幕怎么处理】

很多短剧素材的字幕是烧进画面里的。工具默认：

  1. 镜像关 —— 字幕不会左右颠倒
  2. 不镜像时，裁切会强制偏离中心（0.12~0.88 区域），
     用非对称构图保证去重效果

如果你想按 Meta 新规"字幕全重写"，可以选 cover：
  - 先盖住底部原字幕带
  - 输出后在剪映/PR 里重新加你的字幕
  - cover 高度默认底部 12%，不对自己重新加字幕的位置别太小

───────────────────────────────────────────────────────────────
【账号分配表】

把上百个账号名写进 txt（一行一个，如 accounts\示例.txt），
加 --accounts 跑完会多出"_账号分配表_日期.csv"：
每个输出素材按顺序分给一个账号，一轮分完自动进下一轮。
照着表发布即可，保证同一素材不会被两个账号重复使用。

───────────────────────────────────────────────────────────────
【重要提醒 —— 工具解决不了的部分】

这个工具只做"特征层去重"，让同一母版的多个版本不被判重复。
但 Meta 2026-03 新规判的是"原创性"，以下必须在剪辑阶段人工做：

  1. 叙事重构：不按原片顺序剪，开头 3 秒换钩子
  2. AI 解说轨道：每条素材必配（满足"新增价值"判定）
  3. 字幕全重写，不照抄原片台词
  4. BGM 尽量换 Meta 官方 Sound Library 的音乐

  正确用法：人工按上面 4 条剪出母版 → 工具裂变 N 条 → 按分配表发布

另外：被降权的 Page 光发新素材救不回来，要先发一段时间高原创
内容重置账号信号，期间停发纯片段剪辑。

【常见问题】

Q: 双击 bat 报"Python not found"？
   装个 Python 3.8+（python.org），安装时勾选
   "Add python.exe to PATH"，再双击即可。

Q: 处理很慢？
   确认 GPU 被识别：看开头有没有"NVIDIA NVENC (GPU)"或类似字样。
   如果是 CPU，检查显卡驱动是否装好，或在交互模式里确认没选"只用 CPU"。

Q: 原片有字幕，输出后字幕反了？
   原片有硬字幕时镜像必须关。交互模式选"1=有字幕"，
   或命令行加 --mirror off。

Q: cover 模糊条把我自己的字幕也盖住了？
   cover 盖的是原片底部字幕带，默认 12%。你自己加字幕时别放得太低，
   或者把 --subs-area 调小。

Q: 想让某部剧的素材不互相撞车？
   同一部剧的母版先在剪辑阶段互相拉开（不同开头/不同镜头组合），
   工具再各裂变 5 条；同剧素材间重复画面控制在 30% 以内。

Q: 输出文件名的 v01 v02 是什么？
   同一源素材的第几个版本，参数完全不同，可放心分发。

FB 短剧素材批量去重工具 使用说明
============================================================

一、安装 ffmpeg
----------------
因为 80MB 的 ffmpeg.exe 不方便传仓库，工具目录默认不带 ffmpeg。
任选一种方式：

  A) 安装 imageio-ffmpeg（推荐，最简单）
     pip install imageio-ffmpeg
     （工具会自动找到 imageio 下载的 ffmpeg）

  B) 把 ffmpeg.exe 放进本工具的 bin/ 文件夹
     下载地址：https://www.gyan.dev/ffmpeg/builds/ffmpeg-release-essentials.zip
     解压后把 bin/ffmpeg.exe 复制到「FB去重工具/bin/ffmpeg.exe」

  C) 系统 PATH 里已经有 ffmpeg 也行


二、最简单的用法
----------------
1. 双击「一键去重.bat」
2. 把视频或文件夹拖进黑窗口，回车
3. 每个视频出几版：回车=5
4. 强度：回车=standard（推荐）
5. 字幕处理：回车=keep
6. 输出目录：回车=output/
7. BGM 文件夹：不需要直接回车；需要则拖入文件夹
8. 账号列表：不需要直接回车；需要则拖入 txt 文件
9. 编码方式：回车=自动优先 GPU
10. 并发数：回车=自动
11. 按 y 开始
12. 去 output/ 文件夹取文件


三、命令行用法（更灵活）
------------------------
python dedupe.py -i input/ -n 5
python dedupe.py -i a.mp4 -n 3 --mode strong
python dedupe.py -i input/ -n 5 --bgm bgm/
python dedupe.py -i input/ -n 5 --bgm-vol 0.08
python dedupe.py -i input/ -n 5 --subs cover
python dedupe.py -i input/ -n 5 --subs-area 0.15
python dedupe.py -i input/ -n 5 --mirror on
python dedupe.py -i input/ -n 5 --accounts accounts/账号列表.txt
python dedupe.py -i input/ -n 5 --tag 剧名
python dedupe.py -i input/ -n 5 --gpu cpu
python dedupe.py -i input/ -n 5 --jobs 4


四、目录结构
------------
FB去重工具/
  ├─ bin/                ← 放 ffmpeg.exe（不随 GitHub 上传）
  ├─ input/              ← 源视频放进去
  ├─ output/             ← 去重后的成品
  ├─ bgm/                ← BGM 音乐（.mp3/.m4a/.wav...）
  ├─ accounts/           ← 账号列表 txt
  ├─ dedupe.py           ← 主程序
  ├─ 一键去重.bat        ← Windows 双击启动
  ├─ README.md           ← 项目说明
  └─ LICENSE             ← MIT 许可证


五、账号列表示例
----------------
在 accounts/ 文件夹里新建「账号列表.txt」，每行一个账号：

drama_fans_01
drama_fans_02
drama_fans_03
reel_addict_01
reel_addict_02

运行后 output/ 里会多出一个 _账号分配表_*.csv，
按轮次把每个视频分配到不同账号，同一素材不会落到两个账号。


六、BGM 音量建议
----------------
默认 BGM 音量 0.08，不会再压掉原声。
如果还嫌大，改成 0.05；如果背景音乐本来就轻，改成 0.12。


七、字幕处理
------------
默认 keep：保留原片字幕。
如果要在原片字幕位置重新加 AI 解说字幕，用 --subs cover，
工具会模糊盖掉底部 12% 的字幕带。如果字幕偏高，调 --subs-area 0.15 或 0.18。


八、镜像
--------
默认 off。打开后原片硬字幕会左右颠倒，一般不建议。
关镜像时工具会自动把裁切偏移偏离中心，不靠镜像也能做出差异。


九、速度对比（实测）
--------------------
RTX 5060 Ti 显卡 / 1080×1920 / 15 秒素材：

  GPU（NVENC）：约 3.5 秒/条（4 路并发）
  CPU（libx264）：约 6.1 秒/条（2 路并发）

GPU 失败会自动回退 CPU，不会卡死。


十、注意事项
-----------
1. 工具只做「特征层去重」，Meta 判断原创性更看重叙事重构、AI 解说、字幕重写。
2. 同一部剧的多条素材，建议用不同强度/不同起点/不同 BGM 组合。
3. 不要跨账号复用同一条成品，平台会比对上传历史。
4. 请遵守目标平台社区准则和版权法规。
